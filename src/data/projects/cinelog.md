# CINELOG

CINELOG is a full stack web application developed for discovering and managing movies and TV shows.

The goal of the project was to create a complete entertainment platform where users can explore content from TMDB, view detailed information and manage their own personalized movie and TV show lists.

## Technologies

- Angular
- TypeScript
- Angular Material
- PHP
- MySQL
- REST API
- JWT
- TMDB API

## Features

- Movie and TV show catalogue integrated with TMDB.
- Search functionality for movies and TV shows.
- Detailed information for each title.
- Personalized favorite lists.
- Watched movies and TV shows management.
- User registration and login.
- JWT-based authentication.
- Protected routes.
- Role-based access control.
- Administration features.
- Persistent user data stored in MySQL.
- Responsive user interface.

## Project Goal

The objective was to develop a complete full stack application that combines data from an external API with user-specific information stored in a database.

CINELOG allows users to discover movies and TV shows while maintaining personalized favorites and watched lists linked to their accounts. The project also demonstrates the integration between an Angular frontend, a PHP REST API, MySQL and an external service such as TMDB.
